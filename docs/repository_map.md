# Repository Map

What each file is, and which stage produces it. Run order is top to
bottom; every script writes to `outputs/` and prints its principal
results to standard output.

## Pipeline

| Stage | Script | Produces |
| --- | --- | --- |
| Corpus download | `src/download_data.py` | `data/raw/` |
| Cleaning | `src/clean_text.py` | `data/processed/` |
| Excerpts | `src/prepare_full_sample.py` | 2,000-word excerpts |
| Extraction | `src/extract_signals_openai.py` | six signals — **costly, do not re-run** |
| Completeness | `src/validate_extractions.py` | coverage checks |
| Speech panel | `analysis/10_panel.py` | `outputs/panel/speech_panel.csv` |
| Aggregation | `analysis/12_measures.py` | monthly, quarterly, annual measures |
| Macro download | `src/download_macro.py` | `data/processed/macro_quarterly.csv` |
| External validation | `analysis/13_external_validation.py` | era tables, MRO robustness |
| Dictionary benchmark | `analysis/16_dictionary_benchmark.py` | horse race, construct check |

## Validation rounds

Four rounds were run. Each has a sampler, a sheet builder, and a scoring
script.

| Round | Design | Scoring script |
| --- | --- | --- |
| 1 | 30 speeches, non-blind, excerpt, unseeded | `analysis/15_validation_stats.py` |
| 2 | 60 speeches, blind, full speech, seeded and stratified on model codes | `analysis/17_validation_round2.py` |
| 3 | 53 of the same speeches, independent second coder, excerpt | `analysis/18_coder_reliability.py` |
| 4 | 50 fresh speeches, both coders, blind, identical full text, flat weights | `analysis/19_round4_ceiling.py` |

Supporting scripts:

`src/select_validation_sample.py` draws a round's sample. The round is
selected by `ACTIVE_ROUND`; each round's seed, size, exclusions and
stratification weights are recorded in the `ROUNDS` dictionary, so any
past draw can be reproduced exactly.

`src/build_coding_sheet.py` turns a draw into a blind coding sheet with
full speech text, plus one plain-text file per speech for the cases that
exceed a spreadsheet cell.

`src/build_excerpt_recode_sheet.py` built round 3's excerpt sheet.

`src/build_adjudication_sheet.py` lists the disagreements between two
coders for joint resolution.

`src/triage_second_coder.py` compares an LLM second coder against the
production extraction, for prioritising human attention. Not a
validation tool; see its docstring.

`src/diff_prompts.py` computes the line-level difference between the
production prompt and the revised one, by section, and writes
`outputs/validation/prompt_v1_to_v2_diff.csv`. The claim that version 2
is version 1 plus a fixed set of additions is checked rather than
asserted.

## Reusable modules

| Module | Contains |
| --- | --- |
| `src/measurement_error.py` | misclassification correction and its bounds |
| `src/agreement.py` | Cohen's kappa, exact binomial intervals, sensitivity and specificity |
| `src/timeseries_stats.py` | Newey–West OLS, correlation-as-slope, block bootstrap, Student-t from the incomplete beta |
| `src/dictionary_signals.py` | benchmark vocabularies and scoring |

## Primary data

`data/human/` holds every human code, with speech text stripped so the
files can be versioned:

| File | What |
| --- | --- |
| `human_audit_30.csv` | round 1 |
| `round2_coder_a_full.csv` | round 2, coder A, full speech |
| `round3_coder_b_excerpt.csv` | round 3, coder B, excerpt |
| `round3_adjudication_completed.csv` | the 119 resolved disagreements and the rules they imply |
| `round4_coder_1.csv`, `round4_coder_2.csv` | round 4, both coders, identical text |

`data/raw/` and `data/processed/` are gitignored: they carry ECB speech
text and are regenerated by the pipeline.

## Specifications

`docs/coding_rules.md` is the codebook, currently version 2.
`prompts/extraction_prompt.txt` is version 1 and is what the current
extraction ran under; it is preserved byte-for-byte and must not be
edited. `prompts/extraction_prompt_v2.txt` mirrors the revised rules for
any future extraction. `prompts/README.md` records the split.

## Outputs

`outputs/panel/` holds the speech panel and aggregated measures.
`outputs/validation/` holds every agreement statistic, error rate and
correlation table. `outputs/tables/` and `outputs/figures/` hold the
LaTeX tables and figures the paper includes. `outputs/audit/` holds
coding sheets and speech texts and is gitignored, because those files
carry ECB speech text.
